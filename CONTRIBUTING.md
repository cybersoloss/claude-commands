# Contributing to Claude Commands

Thanks for your interest in contributing!

## How to Contribute

### Reporting Issues

- Use [GitHub Issues](https://github.com/cybersoloss/claude-commands/issues) to report bugs or suggest improvements
- Include your Claude Code version and OS when reporting issues
- Describe the expected vs actual behavior clearly

### Pull Requests

1. Fork the repository
2. Create a feature branch (`git checkout -b add-new-command`)
3. Make your changes
4. Submit a pull request with a clear description of what changed and why

### What We're Looking For

- **New commands** — useful slash commands for Claude Code workflows
- **Command improvements** — better prompts, edge case handling, clearer output
- **Documentation fixes** — typos, unclear instructions, missing examples
- **Design Driven Development command enhancements** — improvements to the workflow commands

### Guidelines

- Each command is a single `.md` file in the root directory
- Command files use Claude Code's slash command format
- Keep commands focused — one clear purpose per command
- Test commands in Claude Code before submitting
- Update `README.md` if you add a new command

### Related Repos

- **[Design Driven Development](https://github.com/cybersoloss/DDD)** — Methodology, spec format reference, templates
- **[Design Driven Development Tool](https://github.com/cybersoloss/ddd-tool)** — Desktop application
